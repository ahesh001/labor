# LaborTracker walkthrough

1. Open [LaborTracker](https://labortracker-cab93.web.app/) and choose **Open demo workspace**. Choose **Continue as guest** if you only want to view the sample dashboard.
2. On **Dashboard**, review open and completed deliveries, flagged handoffs, labor totals, and each crew member's shift progress.
3. Open **Deliveries**. Search or filter the active board, then select a delivery to inspect its assignment, status, notes, and activity. Use **New delivery** to enter a customer, address, scheduled date, optional crew assignment, status, and notes. Save changes from the detail page. Deliveries marked **Delivered** move to **Delivery History**.
4. Open **Delivery History** to find completed work and use **Export CSV** when you need a copy.
5. Open **Labor & Crew** to add a work-hours entry for a crew member, optionally linking it to a delivery. Filter the timesheet by date or crew member, remove an incorrect entry, or use **Export hours CSV**. Admin and Lead demo roles can add crew members; the User role can record hours but cannot add crew.
6. Open **Settings** to change the company label or daily shift target. In demo mode, change the demo role or use **Reset demo data** to restore the fictional sample. Reset replaces demo edits, so export anything you need first.
7. Open **Profile** to see the current session and role. Sign out when finished. Firebase email/password registration and sign-in are available only when that provider and the site domain are enabled for the Firebase project.

Demo changes stay in the current browser. Signed-in workspaces also stay in that browser under the account's local key. See [Data and access](Data-and-Access.md) before using real operational records.
