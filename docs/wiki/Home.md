# LaborTracker

LaborTracker is a browser-based dashboard for dispatching deliveries and recording crew work hours. It combines an active delivery board, crew roster, timesheet, completed-delivery history, and a daily overview. [Open the live app](https://labortracker-cab93.web.app/).

The app includes a fictional demo workspace with 12 deliveries, four crew members, and eight work entries. It is intended to make the workflow easy to explore without using real customer data.

Start with the [Walkthrough](Walkthrough.md). For storage, roles, and account limitations, read [Data and access](Data-and-Access.md). Developers can use [Development](Development.md).

Current release boundary: workspace records are stored in the browser. A signed-in account does not yet synchronize deliveries and timesheets with other devices or team members.
